Arcade Vault
Es una plataforma para jugar online y competir por la mayor cantidad de puntos.

## Usa Spec Driven Design
Basado en /spec y /spec-impl

Siguiendo las buenas practicas recomendadas aquí: https://github.com/Klerith/fernando-skills

## Skills usadas
npx skills@latest add Klerith/fernando-skills

## Development Commands
```bash
# Start development server (watches for changes, rebuilds automatically)
npm run dev

# Build for production
npm run build

# Start production server
npm start

# Run linter
npm run lint
```
After `npm run dev`, the app runs at `http://localhost:3000`.
